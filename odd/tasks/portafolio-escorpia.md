- L2. Evidence: escorpia.com design language (repo `~/Documentos/trabajos/escorpia.com`, `css/home.css:9-60`, `index.html`, `js/home.js`).
  - Tokens: `--bg #040812`, `--bg-alt #08111D`, `--surface #111E31`, `--primary #00D4FF`, `--primary-light #47E8FF`, `--text-soft #C6D1DD`, `--paper #FFFFFF`, `--mist #F2F7FA`, `--line #DCE6EE`, `--muted #44546A`, `--hair-dark rgba(255,255,255,.1)`, `--highlight rgba(0,212,255,.45)`, `--c-line-strong rgba(68,84,106,.45)`, `--r 18px`, `--max 1240px`, `--shadow-light 0 18px 44px rgba(4,8,18,.10)`, `--shadow-dark 0 30px 80px rgba(4,8,18,.65)`. Buttons radius 11px, cards 14-18px, CTA block 28px.
  - Theme: light by default (page `--paper`, text `--bg`); `[data-theme="dark"]` swaps roles (page `--bg`, card `--surface`, muted `--text-soft`); sections with `.on-dark` stay dark in both themes. Theme toggle stored in localStorage.
  - Fonts there: Inter (body) + Space Grotesk (headings) from Google Fonts; mono system stack. Artboards and the portfolio must use system font stacks only.
  - Signature elements: announce bar, sticky blurred header with theme + language switch, dark hero with cyan radial glows, typewriter rotating word, floating rotated browser/phone/chat mock-ups, mono chips with a dot, `<mark>` cyan highlight on headline words, pill badges, logo/stack marquee with gradient mask, services bento with micro-animations (grow bars, equalizer, scan beam, playhead), product card, numbered "how" steps, dark rounded CTA card with a trace SVG (`stroke-dashoffset` pulse), FAQ `<details>` with rotating `+`, dark footer.
  - Motion: `.reveal` via IntersectionObserver (threshold .12) → opacity + `translateY(22px)`, .7s `cubic-bezier(.2,.8,.2,1)`, stagger `.d1-.d3`; pause button (WCAG 2.2.2) + `prefers-reduced-motion`. Escorpia has no 3D, canvas/WebGL or scroll-scrubbed animation: those are new in this redesign.
- L3. Decision: four design directions for S2, all sharing the escorpia DNA from L2, with real content from `content/portfolio.json` (name "Iván Rodrigo Pianto Antón", headline, about, stats, the 8 featured projects, skills, experience; neutral Spanish, no voseo; contact = email + GitHub only; client names stay anonymized as in the content). Project images are inline SVG/HTML mock screens until T7 delivers real screenshots. Every artboard: light/dark theme toggle, motion pause button, `prefers-reduced-motion` fallback (static, fully readable), responsive down to 390 px, no external URLs, no libraries.
  - D1 "Escorpia fiel": the escorpia.com home structure, adapted to a person. Dark hero with typewriter word ("Construyo …") and a 3D cluster of floating browser/phone windows (CSS `perspective`, pointer-parallax tilt, slow float) that spreads apart as the page scrolls; stack marquee; capabilities bento with micro-animations; featured projects as alternating product cards; numbered "Cómo trabajo"; experience timeline; dark CTA card with trace SVG; FAQ; footer. Tradeoff: closest to the Escorpia brand and safest; least surprising.
  - D2 "Órbita 3D": dark-first immersive. Hero full-screen `<canvas>` with a hand-written 3D projection (no libraries): a rotating sphere of nodes labelled with skills, connected by lines, pointer-steered. Scroll scrubs the camera: the sphere unfolds into a flat grid that hands off to the projects section. Projects in a CSS 3D ring carousel (rotateY) driven by scroll/drag/arrow keys, active card expands. Reading sections (skills, experience) switch to Escorpia's light paper style. Tradeoff: biggest wow and most memorable; heaviest on GPU/battery and less scannable.
  - D3 "Historia en scroll": Apple-style pinned narrative. A CSS 3D laptop (lid + base) is pinned while the user scrolls: the lid opens, then its screen swaps per featured project chapter while text panels slide alongside; a phone joins for mobile projects; a side chapter index jumps to any project; then a sticky horizontal-scroll gallery for the remaining projects. Tradeoff: the best stage for real screenshots and storytelling; long scroll, slower to reach one project (mitigated by the chapter index).
  - D4 "Bento vivo": the whole portfolio as one living Escorpia bento grid. 3D tilt tiles with a pointer-following cyan spotlight, project tiles with mini animated UIs, area filter chips, count-up stats, a terminal tile that types commands, an activity heat-map tile; tiles assemble from depth (translateZ/scale) as they enter the viewport via CSS scroll-driven animations (`animation-timeline: view()`) with an IntersectionObserver fallback. Tradeoff: fastest to scan, everything visible at once; less narrative, denser.
